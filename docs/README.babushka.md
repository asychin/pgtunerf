# пгтюн.рф

## Русская бабушка

### Что это за программка, внучок?

**пгтюн.рф** — это помощник для настройки этой твоей базы данных PostgreSQL, внучок. Ты вводишь, сколько у тебя памяти и процессоров, а он тебе говорит, как всё правильно настроить. Удобно, милый!

### Что умеет, родненький?

- Работает с PostgreSQL от 12 до 18 — все версии, внучок
- Поддерживает Линукс, Виндоус и этот... как его... Мак
- Для интернета, для магазина, для хранения, для домашнего компьютера — для всего!
- Быстрый диск, обычный диск, сетевой диск — какой есть, такой и ставь
- Копируется одной кнопочкой, очень удобно
- 5 языков, внучок! Есть даже для гопников, но ты же не такой, правда?
- Тёмная тема — чтобы глазки не уставали вечером
- И даже через эту вашу командную строку работает!

### Как запустить, внучок?

```bash
yarn        # подождать, пока всё установится, милый
yarn dev    # запустить программку (порт 5173, внучок)
yarn test   # проверить, всё ли работает
yarn lint   # проверить, красиво ли написано
yarn build  # собрать для работы, родненький
```

### Командная строка (если ты такой умный, внучок)

```bash
# Получить настройки в JSON, внучок (это по умолчанию)
curl "https://domain/api/config?db_version=18&os_type=linux&db_type=web&total_memory=2&total_memory_unit=GB&cpus=2&connections=300&hd_type=ssd"

# Получить настройки файлом, внучок
curl "https://domain/api/config?db_version=18&os_type=linux&db_type=web&total_memory=2&total_memory_unit=GB&cpus=2&connections=300&hd_type=ssd&format=conf"

# Получить настройки ALTER SYSTEM, внучок
curl "https://domain/api/config?db_version=18&os_type=linux&db_type=web&total_memory=2&total_memory_unit=GB&cpus=2&connections=300&hd_type=ssd&format=alter"
```

### Параметры, внучок

| Параметр | Что туда писать, милый | Если не напишешь |
|---|---|---|
| `db_version` | 12, 13, 14, 15, 16, 17, 18 | 18 |
| `os_type` | linux, windows, mac | linux |
| `db_type` | web, oltp, dw, desktop, mixed | web |
| `total_memory` | число, внучок | — |
| `total_memory_unit` | GB, MB | GB |
| `cpus` | сколько процессоров, родненький | — |
| `connections` | число (не меньше 20, внучок) | — |
| `hd_type` | ssd, hdd, san | ssd |
| `format` | json, conf, alter | json |
